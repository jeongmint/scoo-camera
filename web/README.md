# SCOO Camera 🌱📸

**오늘의 한 컷, 초록이 되는 순간.**

캐논 IXUS/IXY 시절의 실버 디지털 카메라에서 영감을 받은 웹 카메라입니다. 사진을 찍거나 불러와 빈티지 색감을 입히고, 사진을 먹고 자라는 작은 마리모와 일상을 기록합니다. 특정 카메라 모델의 색 재현을 보장하는 에뮬레이터는 아닙니다.

## 시작하기

Node.js 20 이상만 있으면 됩니다. 설치할 패키지나 API 키가 없습니다.

```sh
git clone https://github.com/jeongmint/scoo-camera.git
cd scoo-camera
npm run dev
```

브라우저에서 **http://localhost:3000**을 엽니다. `PORT=4000 npm run dev`로 포트를 바꿀 수 있습니다.

휴대폰에서 실제 카메라를 쓰려면 **HTTPS로 호스팅한 주소**를 여세요. 휴대폰에서 PC의 HTTP IP 주소로 접속하면 카메라 권한이 제공되지 않을 수 있습니다. 카메라 권한을 거절해도 사진 불러오기와 샘플 촬영은 사용할 수 있습니다.

## 사용법

1. **카메라 켜기**를 누르고 권한을 허용하거나 **사진 불러오기**로 앨범 사진을 선택합니다.
2. **Warm CCD / Soft Flash / Mint Day / Mono 2006** 중 색을 고릅니다.
3. 디카 오른쪽의 버튼으로 앞·뒤 카메라, 1–3배 디지털 줌, 플래시 느낌, 날짜 인쇄를 조절합니다.
4. **일상 / 음식** 모드를 고르고 가운데 초록 셔터를 누릅니다.
5. 마리모가 EXP를 받고 자랍니다. 마리모를 누르면 반응하고, 이름 옆 연필로 이름을 바꿀 수 있습니다.
6. 아래 앨범의 사진을 열어 **저장**하거나 삭제합니다. 지원되는 모바일 브라우저에서는 시스템 공유 메뉴를 열어 사진 앱에 저장할 수 있습니다.

카메라가 켜지기 전에는 직접 만든 SVG 창가 장면이 표시됩니다. 이 장면도 셔터로 체험할 수 있으며 앨범 상세에 **샘플 체험**이라고 표시됩니다. 첨부 참고 사진은 공개 저장소에 포함하지 않았습니다.

## 성장 규칙

| 항목                       |     EXP |
| -------------------------- | ------: |
| 일상 모드                  |     +12 |
| 음식 모드                  |     +20 |
| 적절한 밝기                | 최대 +5 |
| 명암 분포·인접 픽셀 변화량 | 최대 +5 |

100 EXP마다 1레벨이 오릅니다. 크기는 누적 EXP에 따라 점진적으로 증가하며 유리병 안의 표시 크기는 상한이 있습니다. 사진 삭제는 이미 받은 성장에 영향을 주지 않습니다.

**현재 버전은 음식 모드를 사용자가 직접 고릅니다.** 음식 인식 모델이나 생성형 AI는 연결하지 않았습니다. 사진 보너스는 원본의 작은 픽셀 표본으로 계산하는 간단한 기술적 추정치이며, 사진의 예술성·구도·음식 여부를 평가하지 않습니다. 풍부한 노이즈에도 보너스가 붙을 수 있습니다. 향후 음식 인식과 미적 평가 모델을 연결할 수 있는 첫 프로토타입입니다.

## 사진 처리와 보관

- 촬영, 크롭, 필터, 그레인, 비네팅, 날짜 인쇄는 브라우저 Canvas에서 처리합니다.
- 결과는 **1200 × 900 JPEG**입니다. 라이브 미리보기는 CSS로 가볍게 표현하며, 저장 시 픽셀 처리를 하므로 약간 다를 수 있습니다.
- 플래시는 **밝기를 올리는 이미지 효과**입니다. 기기의 실제 LED를 켜지 않습니다.
- 사진과 촬영별 EXP는 **IndexedDB**, 이름·성장 상태는 **localStorage**에 저장됩니다.
- 앱은 사진을 서버로 업로드하지 않습니다. 기기를 바꾸거나 다른 브라우저를 쓰면 기록이 공유되지 않습니다.
- 브라우저 데이터 삭제·비공개 모드·저장 공간 정리로 기록이 사라질 수 있습니다. 중요한 사진은 내려받아 보관하세요.
- 사진 저장에 실패하면 EXP를 지급하지 않습니다. 성장 상태 저장이 실패하면 화면에 안내합니다.
- Google Fonts를 불러오며, 연결할 수 없으면 시스템 글꼴로 표시합니다.
- 카메라는 앱을 숨기거나 전원을 끄면 스트림을 중지합니다. 다시 사용할 때 켜 주세요.

## 프로젝트 구조

```text
dist/
  index.html          화면 및 접근성 마크업
  style.css           반응형 디카 UI / 유리병 / 애니메이션
  app.js              카메라 / 앨범 / 저장 / 마리모 상호작용
  core.js             필터 / 픽셀 품질 추정 / 성장 계산
  assets/sample.svg   직접 만든 샘플 장면
scripts/serve.mjs      의존성 없는 로컬 정적 서버
tests/core.test.mjs    품질 / 보상 / 성장 / 필터 테스트
```

## 확인

```sh
npm run check
npm test
```

핵심 로직은 Node 내장 테스트 러너로 검증합니다. 실제 카메라 권한, 전면·후면 전환, iOS 공유 동작은 대상 기기에서 별도로 확인하세요. 카메라를 제공하지 않는 환경에서는 샘플 촬영과 이미지 불러오기를 사용할 수 있습니다.

## 배포

`dist/`를 HTTPS 정적 호스팅에 배포하면 됩니다. 빌드 단계와 서버 API가 필요 없습니다. GitHub Pages라면 `dist/` 내용을 게시 디렉터리로 업로드하거나 Actions로 Pages 아티팩트를 배포하세요. 루트에서 모듈을 `file://`로 직접 열지 말고 정적 서버를 사용하세요.
